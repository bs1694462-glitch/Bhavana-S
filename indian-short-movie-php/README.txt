Indian Short Movie - PHP Conversion
------------------------------------

This is a complete conversion of the Indian Short Movie website from React to PHP, HTML5, CSS3, and Vanilla JS.

Features:
- Preserved professional cinematic design
- Fully functional 9-genre navigation
- Filmmaker directory with 2 real independent creators
- Professional film submission form (matching reference)
- Admin Dashboard UI
- Integrated phone, WhatsApp, and social links
- LocalStorage based Watchlist system

Technical Stack:
- PHP 8.x
- Tailwind CSS (via CDN for exact styling)
- Vanilla JavaScript
- Font: Outfit & Inter

Deployment:
1. Upload the contents to any PHP-enabled web server.
2. Ensure the directory structure is preserved.
3. Access index.php to start.
